# Project state

Last verified: 2026-09-25

## Product
The corporate website for **Itqan Pharmaceutical Industries**, a pharmaceutical manufacturer in Amman, Jordan. It replaces itqanpharma.com, whose current site contains template contamination. B2B goals, in order:
1. business-cooperation enquiries (contract manufacturing and partnership);
2. product information requests;
3. corporate credibility.

English only at launch (owner, 2026-09-25).

## Current users / actors
- Visitors: distributors, partners, healthcare and pharma professionals, and the public.
- Right now: the owner and friends reviewing the preview at https://courageous-caramel-8493e6.netlify.app.

## Stack
- **Framework:** Next.js 16 (App Router), TypeScript strict, Tailwind CSS v4, React 19.
- **Output:** a static export (`out/`) served from Netlify's CDN. There is no server runtime (ADR-006).
- **3D:** three.js 0.184, loaded lazily on the home page and the brand sheet only.
- **Font:** Host Grotesk, self-hosted via `@fontsource/host-grotesk` and `next/font/local`.
- **Images:** pre-optimised WebP sets generated by `npm run images` from the handoff originals (ADR-008).
- **Forms:** Netlify Forms (ADR-009).

## Design system
Everything is specified in `design_handoff_itqan_website/README.md`.
- **Tokens:** CSS variables in `src/app/globals.css` (dark by default, light via `html[data-theme=light]`), exposed to Tailwind through `@theme inline`.
- **Motion:** described in `globals.css` (CSS intro) and `SiteRuntime` (scroll).

## Known issues
- **Category slugs are unconfirmed.** `/product-category/<slug>/` uses the design catalogue's slugs. The live site's slugs are unknown until the crawl, so any that differ need 301s.
- **Local cache headers unverified.** `netlify dev` did not apply the custom `Cache-Control` headers for `/_next/static/*` and `/images/*`. Confirm them on the real deploy with `curl -I`.
- **Stale brand-sheet copy.** The type section still says "Funnel Display + Funnel Sans", but the site uses Host Grotesk. It's kept verbatim; send it to Claude Design as a correction.
- **Legacy query strings.** The old prototype URLs with `?c=` / `?p=` redirect correctly but keep the query string (harmless).

- Never invent medical or corporate facts. Unknown means `null`, which is not rendered. See CLIENT_QUESTIONS.md.

- Keep the architecture small: no database, auth, CMS or admin.
